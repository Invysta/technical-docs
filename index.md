## Integration Guides

The following technical reference documents are available for Invysta AAK device authentication.

---

### [OAuth / OpenID Connect Integration Guide](invysta_oauth_integration.pdf)
For platforms integrating with the Invysta managed authentication service via standard OAuth 2.0 / OIDC. Covers client registration, authorization flow, device enrollment, MFA configuration, and fault tolerance.

---

### [Embedded Service Deployment Guide](invysta_binary_deployment_guide.pdf)
For platforms deploying the Invysta authentication service within their own infrastructure or as an Invysta-hosted dedicated instance. Covers self-hosted and Invysta-hosted options, the proxy-based registration and authentication flow, API security tiers, and high availability.
